## 1. 产品概述

### 1.1 产品背景

Wallpaper Engine 是 Windows 平台最受欢迎的动态桌面壁纸软件，其 Scene 类型壁纸资源以 `.pkg` 私有封装格式存储于 Steam Workshop 目录中。

社区开源工具 [RePKG](https://github.com/notscuffed/repkg)（MIT 协议）提供了命令行方式解包 PKG 并转换 TEX 纹理为图片的能力。

**现有痛点：**
- RePKG 仅有 CLI 界面，普通用户难以使用
- 现有社区 GUI 方案（WinForms / Wails / Tauri 等）均停留在"调用 CLI → 全量解包 → 展示输出目录"的浅层封装模式
- 用户无法在解包前预览壁纸内容，导致不必要的磁盘空间浪费

### 1.2 产品定位

**RePKG GUI** 是一款面向 Wallpaper Engine 普通用户的 Windows 桌面工具。

**核心价值主张：**
> 在不解包全部文件的前提下，以可视化列表（缩略图 + 元数据）方式浏览 PKG 壁纸内容，并支持按需选择性解包。

### 1.3 核心设计理念

| 理念 | 说明 |
|------|------|
| 🎵 像音乐播放器一样管理壁纸 | 先看缩略图再决定解不解，而不是"全解完进文件夹翻" |
| 📊 元数据优先 | 标题、作者、类型、大小一目了然，细节按需展开 |
| ✂️ 选择性解包 | 只解用户勾选的项目，避免磁盘空间浪费 |
| 📚 零学习成本 | 不需要了解 CLI 参数、JSON 结构或命令行环境 |

### 1.4 竞品分析

| 竞品 | 技术方案 | 局限性 |
|------|----------|--------|
| notscuffed/repkg | C# CLI | 无 GUI，命令行操作 |
| zhongyang219/RePkgUiTool | WinForms + 调 repkg.exe | 简单套壳，全量解包 |
| Kakune55/repkg-gui | Wails + Vue.js | Go 后端 + Web 前端，CLI 套壳 |
| NaiHeeeee/repkg-gui | Tauri + React | Rust 后端，CLI 套壳 |
| XANXUS2/-RePKG-GUI-Python | Python | 简易版，功能有限 |

**本产品差异化：** 以上竞品均为"全量解包 + 展示输出目录"模式，未做元数据预览层。

## 2. 用户分析

### 2.1 目标用户画像

| 用户类型 | 特征描述 | 核心诉求 |
|----------|----------|----------|
| 🎮 普通玩家 | 拥有数十至数千个 WE 壁纸，不懂命令行 | 快速预览、挑选、提取喜欢的壁纸素材 |
| 🎨 素材创作者 | 需要参考/复用 WE 场景中的贴图、模型 | 精准提取特定类型资源（TEX → PNG） |
| ⚙️ 高级用户 | 批量管理 Workshop 目录，了解 JSON 结构 | 批量筛选、按标签/作者分类导出 |

### 2.2 用户场景

**场景一：普通玩家浏览壁纸**
> 小明有 500 个 Wallpaper Engine 壁纸，想找几个风景类的解包出来分享给朋友。他打开 RePKG GUI，看到所有壁纸的缩略图，按标签筛选"Nature"，勾选几个喜欢的，一键解包。

**场景二：素材创作者提取资源**
> 小红是 3D 美术，需要从某个 WE 场景中提取贴图素材。她找到目标壁纸，查看详情确认包含所需资源，仅勾选 `.png` 和 `.obj` 文件类型进行解包。

**场景三：高级用户批量管理**
> 小蓝需要按作者分类导出壁纸。他使用批量筛选功能，按作者名称过滤，批量解包到按作者命名的文件夹中。

### 3.2 功能详情 —— 目录扫描与 PKG 发现（P0）

**功能描述：**
用户选择一个目录（典型路径如 `Steam\steamapps\workshop\content\431960`），GUI 递归扫描所有 `.pkg` 文件并逐个提取元数据。

**触发方式：**
- 点击"打开目录"按钮
- 拖拽文件夹到窗口
- 命令行参数传入路径

**技术要求：**

| 属性 | 说明 |
|------|------|
| 扫描策略 | 异步后台扫描，不阻塞 UI；扫描进度实时显示（已发现 N 个 PKG） |
| 性能要求 | 5000 个 PKG 文件扫描 + 元数据提取 < 60 秒（SSD） |
| 错误处理 | 损坏 PKG 跳过并标注"读取失败"，不影响其他文件 |
| 默认路径 | 首次运行时自动检测 Steam 安装路径，提示用户确认 Workshop 目录 |

**验收标准：**
- [ ] 支持拖拽文件夹导入
- [ ] 扫描过程可取消
- [ ] 进度条实时更新
- [ ] 错误文件有明确提示

### 3.3 功能详情 —— 元数据提取（P0）

**功能描述：**
对每个 PKG 文件，仅读取其头部 + `project.json` 条目（不解密全部内容），提取以下字段用于列表展示。

**提取字段：**

| 字段 | 来源 | 展示位置 | 示例值 |
|------|------|----------|--------|
| Title | project.json → title | 列表主标题 | Mountain Lake |
| Author | project.json → author | 列表副标题 | NatureArt |
| Type | project.json → type | 类型图标/标签 | scene / video / web |
| Preview | PKG 内 preview.jpg 流 | 列表缩略图 | (二进制图片) |
| File Size | 文件系统 .Length | 列表辅助信息 | 45.2 MB |
| Workshop ID | project.json → workshopid | 详情面板 + 链接 | 12345678 |
| Tags | project.json → tags[] | 详情面板标签组 | Nature, Relaxing |
| IsExtracted | 输出目录存在性检测 | 列表状态标记 | ✓ 已解包 / 未解包 |

**技术要点：**
- 利用 RePKG.Core 的 `PkgReader` 流式读取能力
- 仅解压 `project.json` 和 `preview.jpg` 两条 entry，避免全量解密
- 元数据提取在后台线程执行，UI 通过数据绑定实时刷新

### 3.4 功能详情 —— 缩略图预览（P0）

**功能描述：**
以网格或列表形式展示所有扫描到的壁纸，每项包含缩略图 + 标题 + 作者 + 类型图标。

**视图配置：**

| 属性 | 说明 |
|------|------|
| 视图模式 | 网格视图（默认，缩略图为主）+ 列表视图（文字为主，缩略图较小）可切换 |
| 缩略图尺寸 | 网格模式：200×200px；列表模式：64×64px |
| 缓存策略 | 一级：内存缓存（最近 500 张）；二级：磁盘缓存（缩略图存为 JPEG 到 `%AppData%\RePKG.Gui\Thumbs\`） |
| 加载策略 | 虚拟滚动 + 懒加载，仅渲染可视区域内的缩略图 |
| 类型标识 | 缩略图右下角叠加类型图标：🎬=scene / 🌍=web / 📹=video |
| 双击行为 | 打开详情面板，显示完整元数据 + 解包按钮 |

**验收标准：**
- [ ] 网格/列表视图可切换
- [ ] 滚动流畅（5000 项不卡顿）
- [ ] 缩略图加载有占位符
- [ ] 类型图标正确显示

### 3.5 功能详情 —— 详情面板（P0）

**功能描述：**
选中或双击某一项后，底部/侧边展开详情面板，展示完整信息。

**展示内容：**
- 大尺寸预览图（400px 宽）
- 标题（大字）
- 作者（可点击跳转 Steam 主页）
- Workshop ID（可点击跳转 workshop 页面）
- 类型标签 + 文件大小 + 本地路径
- Tags 标签组（如 Nature / Anime / Cyberpunk）
- "解包"按钮 + "解包选项"展开
- 高级折叠区：原始 `project.json` 内容（只读文本框，方便高级用户查阅）

### 3.6 功能详情 —— 选择性解包（P0）

**功能描述：**
用户勾选若干壁纸项 → 点击"解包选中" → 弹出解包选项对话框 → 确认后异步执行。

**底层调用：**
直接通过 RePKG.Core 的 `PkgExtractor` 类执行解包，而非启动 `repkg.exe` 子进程。这样可获得结构化异常和细粒度进度回调。

**解包选项：**

| 选项 | 说明 |
|------|------|
| 输出目录 | 默认 `.\output\`；可自定义；勾选"使用壁纸名称作为子文件夹"（对应 `-n` 参数） |
| 文件过滤 | 仅提取图片（.png/.jpg）、仅提取模型（.obj/.fbx）、排除音频 … 对应 `-e` / `-i` 参数 |
| TEX 转换 | 默认开启 TEX → PNG（对应默认行为）；可关闭（`--no-tex-convert`） |
| 覆盖策略 | 默认"跳过已存在"；可选"覆盖全部"（`--overwrite`） |
| 进度反馈 | 每个 PKG 解包进度实时显示；完成后弹通知；错误项标红并展示日志 |

**验收标准：**
- [ ] 支持多选解包
- [ ] 解包过程可取消
- [ ] 进度实时显示
- [ ] 错误有明确提示
- [ ] 完成后可打开输出文件夹

## 5. 数据模型

### 5.1 WallpaperItem（列表项）

对应每个 PKG 文件在 UI 中的展示与状态：

```csharp
public class WallpaperItem
{
    public string Title { get; set; }           // project.json.title
    public string Author { get; set; }          // project.json.author
    public string Type { get; set; }            // scene | web | video | application
    public Bitmap PreviewImage { get; set; }    // PKG 内 preview.jpg（流式读取）
    public long FileSize { get; set; }          // PKG 文件字节数
    public string WorkshopId { get; set; }      // project.json.workshopid
    public string[] Tags { get; set; }          // project.json.tags[]
    public string PkgPath { get; set; }         // 本地 PKG 文件路径
    public bool IsExtracted { get; set; }       // 输出目录是否已存在
    public DateTime ScanTime { get; set; }      // 元数据提取时间（用于缓存失效）
}
```

### 5.2 ProjectInfo（JSON 映射）

完整映射 `project.json` 所有字段，供详情面板"高级"折叠区展示：

```csharp
public class ProjectInfo
{
    public string Title { get; set; }
    public string Description { get; set; }
    public string File { get; set; }            // 主入口文件相对路径（如 scene.json）
    public string Preview { get; set; }         // 缩略图相对路径（如 preview.jpg）
    public string Type { get; set; }            // scene / web / video / application
    public string Visibility { get; set; }      // public / private
    public string WorkshopId { get; set; }      // Steam Workshop 物品 ID
    public string AuthorSteamId { get; set; }   // 作者 Steam ID
    public string[] Tags { get; set; }          // 标签数组
    public long Timestamp { get; set; }         // 时间戳
    public GeneralProperties General { get; set; }  // 嵌套对象（scheme color 等）
}
```

### 5.3 ExtractOptions（解包配置）

```csharp
public class ExtractOptions
{
    public string OutputDirectory { get; set; }      // 输出根目录
    public bool UseNameAsFolder { get; set; }        // 对应 -n
    public string[] IncludeExtensions { get; set; }  // 对应 -e
    public string[] ExcludeExtensions { get; set; }  // 对应 -i
    public bool ConvertTexToImage { get; set; }      // 对应默认行为 / --no-tex-convert
    public bool OverwriteExisting { get; set; }      // 对应 --overwrite
    public bool CopyProjectFiles { get; set; }       // 对应 -c
}
```

## 8. 风险与依赖

### 8.1 风险登记

| # | 风险描述 | 影响 | 概率 | 缓解措施 |
|---|----------|------|------|----------|
| 1 | 上游 RePKG API 变更导致引用断裂 | 高 | 中 | 锁定版本 + 抽象适配层隔离 |
| 2 | PKG 加密/新版格式无法解析 | 中 | 低 | 异常捕获 + 跳过 + 上报 |
| 3 | 缩略图内存暴涨（数千张大图） | 中 | 中 | 虚拟滚动 + LRU 缓存淘汰 |
| 4 | 用户无 .NET Runtime 无法启动 | 低 | 低 | 自包含发布（单文件 exe） |
| 5 | WE 更新 PKG 格式导致大面积失败 | 高 | 低 | 关注上游更新 + 快速响应 |

## 9. 附录

### 9.1 RePKG 核心 CLI 命令参考

| 命令 | 用途 | 关键参数 |
|------|------|----------|
| `repkg extract <file>` | 解包 PKG / 转换 TEX | `-o` 输出目录 / `-c` 复制项目文件 / `-n` 用名称命名 / `-e` 仅提取指定扩展名 / `-i` 忽略扩展名 / `-t` 批量转 TEX / `-s` 单目录 / `-r` 递归 / `--no-tex-convert` / `--overwrite` |
| `repkg info <file>` | 查看 PKG/TEX 信息（不解包） | `-p` 提取 project.json 指定键 / `-e` 打印条目 / `-s` 排序 / `-b` 排序字段 / `--title-filter` 标题过滤 |

### 9.2 project.json 标准字段

| 字段 | 说明 |
|------|------|
| `title` | 壁纸显示名称（必填） |
| `description` | 描述文本 |
| `file` | 主入口文件相对路径（如 scene.json） |
| `preview` | 缩略图相对路径（如 preview.jpg） |
| `type` | scene / web / video / application |
| `visibility` | public / private |
| `workshopid` | Steam Workshop 物品 ID |
| `authorsteamid` | 作者 Steam ID |
| `tags[]` | 标签数组 |
| `timestamp` | 时间戳 |
| `general` | 嵌套对象（properties / schemecolor 等用户可配置项） |
